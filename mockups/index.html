Legend & rules

  • Baseline (current/) — the control: real markup, real global.css, no-op variant.css. It should always look like the live homepage.
  • Variants (YYYY-MM-DD-<name>/) — one design variable at a time, applied CSS-only in this order: tokens → type → components → layout. Never fork global.css; only override.
  • Content — real site copy only. The (555) 123-4567 phone and the email are the existing (placeholder) values from src/site.config.ts; never invent contact details or prices.
  • Promotion — adopting a variant means a design/<name> branch off feature/astro-rebuild, the concept applied to the real Astro components/CSS, and a PR. Verdicts are documented in docs/notes.md.
