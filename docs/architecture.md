# Architecture

## Runtime Shape

- Static site generated by Hugo.
- Theme is `ananke`.
- Netlify build command is `hugo --gc --minify` and output directory is `public/`.

## Key Files

| Path | Role |
| --- | --- |
| `hugo.toml` | Site configuration, SEO params, menu, and markup settings. |
| `content/` | Markdown content for home, about, contact, services, small jobs, and service areas. |
| `layouts/_default/baseof.html` | Custom default layout wrapper. |
| `netlify.toml` | Netlify build and context settings. |
| `themes/` | Hugo theme dependency location. |

## Data Flow

Markdown content and Hugo config are rendered into static files in `public/`, then served by the host.
